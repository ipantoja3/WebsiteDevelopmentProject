Concept

Despite it's seeming simplicity, this concept took me quite awhile to come up with. I quite enjoyed the code aspect, but was honestly not looking forward to the extensive research and writing any other topic would require. This topic, being covered in class, allowed me to skip this stage and focus on the code of the website. The website was essentially code-complete before I'd even settled on a topic. I believe the topical nature of this website is an effective demonstration that I've mastered the course material.

Growth

When I started this class, I had virtually zero knowledge of HTML, CSS, or JavaScript. I've used all 3 in the creation of this website. I'm admittedly not a fan of CSS, but I find HTML and especially JavaScript to be great fun to use. HTML is very straightforward and JavaScript is so versatile. CSS is necessary, but incredibly confusing with plenty of unclear rules and edge cases. CSS was not designed for how we use it in the modern day and it shows. Throughout the pages I'll elaborate on the strategies used in my code and what I've learned over the course of this class.
